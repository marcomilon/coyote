ventas314.com crea y aloja páginas web sencillas para negocios. Guardamos lo mínimo para que eso funcione.

## Qué guardamos

- **Tus respuestas**: el nombre del negocio, la descripción, el número de WhatsApp, la dirección y las redes que escribiste. Con ellas se genera y se muestra tu página web.
- **Tu correo**, para avisarte cuando tu página web esté lista y para enviarte el enlace a «Mis páginas web» cuando lo pidas. No aparece en tu página web, no lo reciben los modelos de inteligencia artificial y no te enviamos publicidad.
- **El contenido de tu página web**, para que puedas editarla sin generarla de nuevo.
- **Un registro de cada solicitud** (respuestas y resultado de la revisión de seguridad) durante 90 días, para investigar abusos.
- **Tu dirección IP, solo como un código irreversible (hash)**, para limitar cuántas páginas web se crean por día.

No usamos herramientas de analítica, ni en esta aplicación ni en las páginas web que creamos. Esta aplicación usa una sola cookie, y solo si eliges un país en la página de inicio: guarda ese país para mostrarte sus precios y su forma de hablar. Las páginas web que creamos no usan cookies. No vendemos ni compartimos tus datos con terceros con fines publicitarios.

## Quién procesa tus datos

Todo se aloja en Amazon Web Services, que también envía nuestros correos. El diseño y los textos se generan con modelos de inteligencia artificial de Anthropic (Claude) y de Amazon Bedrock, que reciben tus respuestas y tus fotos para crear la página web y no las usan para entrenar sus modelos. Para que tu página web muestre tus datos de contacto, esos modelos también reciben tu número de WhatsApp, tu teléfono, tu dirección y tus redes. Tu correo personal nunca lo reciben.

Para frenar a los robots, los formularios de crear una página web, pedir el enlace de entrada y reportar una página web pasan por Cloudflare Turnstile, que revisa tu navegador y tu dirección IP para comprobar que eres una persona. No usa cookies de publicidad ni te sigue a otros sitios.

Si registras un dominio desde Mi página web, lo registramos con nuestros datos: tus datos personales no van al registrador del dominio. Si después pides el dominio a tu nombre, en ese momento tus datos van a Porkbun, el registrador, y al registro del dominio.

## Las páginas web que creamos

Una página web publicada es pública: cualquiera puede ver el nombre, la descripción, el WhatsApp, la dirección y las redes que pusiste. Los visitantes de esas páginas no son rastreados. Las páginas cargan tipografías y librerías desde servicios públicos (Google Fonts, Tailwind, jsDelivr, cdnjs, unpkg), que reciben la dirección IP del visitante como cualquier servidor web.

## Cómo borrar tus datos

Abre **Mi página web** con el enlace que recibiste al crear tu página web y elige «Borrar mi página web y mis datos». También puedes llegar a ella desde **Mis páginas web**, con un enlace que te enviamos a tu correo. Se eliminan las páginas, el contenido y el texto de tus solicitudes; tu correo se borra con tu última página web.

## Tus derechos

Según tu país (por ejemplo LGPD en Brasil, LFPDPPP en México, Ley 1581 en Colombia, Ley 25.326 en Argentina) puedes acceder a tus datos, corregirlos y pedir que se eliminen. En Mi página web puedes hacer las tres cosas.
