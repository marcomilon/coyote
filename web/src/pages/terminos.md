Al crear una página web con ventas314.com aceptas estas reglas.

## Qué ofrecemos

Una página web para tu negocio, generado a partir de tus respuestas y alojado por nosotros. El servicio se ofrece tal cual, sin garantía de disponibilidad. Los textos se generan con inteligencia artificial: revisa tu página web antes de publicarla y corrige lo que haga falta desde Mi página web.

Desde Mi página web también puedes registrar un dominio para tu página web. Lo registramos nosotros, a nuestro nombre, por un año y sin renovación automática, y lo usamos solo para tu página web. Si lo pides, te lo pasamos a tu nombre sin costo mientras esté pagado; para llevarlo a otro registrador hay que esperar 60 días desde que se registró. El dominio sigue las reglas del registrador (Porkbun) y del registro del dominio.

## Qué no se permite

No creamos páginas web para: servicios sexuales o contenido para adultos; juegos de azar, apuestas o loterías; bares, licorerías, tabaco o vapeo; casas de empeño o de cambio; drogas, medicamentos sin receta o armas; esquemas de inversión, pirámides o préstamos con pago por adelantado; suplantar a bancos, entidades públicas, empresas de mensajería u otras marcas; pedir contraseñas, claves, números de tarjeta o códigos; piratería, documentos falsos o falsificaciones; campañas políticas o proselitismo; contenido de odio o que sexualice a menores; ni nada ilegal.

Podemos rechazar una solicitud o retirar una página web sin previo aviso si incumple estas reglas o si recibimos reportes. Cada página web tiene un enlace «Reportar».

## Tu contenido

Eres responsable de que la información de tu página web sea cierta y de tener derecho a usarla. La página web es tuya: puedes editarla, ponerla fuera de línea o borrarla cuando quieras desde Mi página web.

## Tu enlace de acceso

El enlace a Mi página web es la llave de tu página web. Guárdalo: quien lo tenga puede editarla o borrarla.

## Límites

Hay un límite de páginas web por día y de versiones nuevas por página web. Todas las páginas web muestran al pie «Página web creada con ventas314.com».
